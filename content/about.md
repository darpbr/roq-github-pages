# About

Este site usa o `quarkus-roq` como gerador estático.

Os arquivos principais ficam nestes diretórios:

- `content/` para páginas
- `data/` para dados YAML ou JSON
- `public/` para arquivos públicos
- `.github/workflows/` para deploy no GitHub Pages
